## 🚀 About the Repository

**Code-With-Harsh** is my personal C++ practice space where I document my programming journey, strengthen core concepts, and build problem-solving skills.

This repository brings together topic-wise implementations, practice programs, and algorithmic concepts — starting with C++ fundamentals and moving towards more advanced Data Structures and Algorithms.

### 🎯 What you'll find here

- **C++ fundamentals** — basic programs, functions, and mathematical problem-solving.
- **Data Structures** — arrays, linked lists, stacks, queues, heaps, trees, and graphs.
- **Algorithms** — recursion, sorting, and graph-related problem solving.
- **Practice code** — implementations and experiments as I learn.
- **Continuous improvement** — code and topics evolve as my understanding grows.

> This is a learning repository, not a claim that every topic is complete. New implementations and improvements are added along the way.

## ⚙️ Getting Started

Want to explore or run the programs locally? Follow these steps.

### 1. Clone the repository

```bash
git clone https://github.com/harshyadav-25/Code-With-Harsh.git
cd Code-With-Harsh
```

### 2. Make sure a C++ compiler is installed

Check your compiler version:

```bash
g++ --version
```

You can use **GCC/G++**, **Clang**, or another C++-compatible compiler.

### 3. Compile a program

For example, to compile a file named `first.cpp`:

```bash
g++ first.cpp -o first
```

### 4. Run it

**Linux / macOS / WSL:**

```bash
./first
```

**Windows PowerShell:**

```powershell
.\first.exe
```

Replace `first.cpp` with the source file you want to run.
